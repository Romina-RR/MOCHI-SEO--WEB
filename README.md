# 🍱 Mochi-seo — Sitio Web para Restaurante Asiático

Sitio web responsivo y moderno desarrollado para **Mochi-seo**, enfocado en destacar la identidad visual de la marca y ofrecer una experiencia de usuario fluida para el menú de antojitos asiáticos.

🌐 **Demo en Vivo:** [https://romina-rr.github.io/MOCHI-SEO--WEB/](https://romina-rr.github.io/MOCHI-SEO--WEB/)  
🎨 **Caso de Estudio en Behance:** [https://www.behance.net/gallery/165601269/Mochi-seo](https://www.behance.net/gallery/165601269/Mochi-seo)

---

## 🛠️ Tecnologías & Herramientas Usadas

- **Front-End:** HTML5 Semántico, CSS3 (Flexbox & CSS Grid), JavaScript (ES6+).
- **Diseño & Branding:** Figma, Ilustración e Identidad Visual.
- **Despliegue:** GitHub Pages.

---

## ✨ Características Principales

- **Diseño Adaptativo (Responsive):** Optimizado para dispositivos móviles, tablets y escritorio.
- **Coherencia de Marca:** Integración de la paleta de colores, tipografía y personaje ilustrado de la marca.
- **UI/UX enfocado en conversión:** Navegación simple con llamada a la acción (CTA) directa al menú y contacto.
